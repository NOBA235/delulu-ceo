App Map & System Reference

Delulu CEO

A satirical startup pitch generator turning questionable life choices into venture-backed business empires.

System Architecture & Core Journey

Reference Route: Tracing One Request

  1. Stop 1: User Entry Point (components/confession-form.tsx)
    Validates length client-side with lib/validation/pitch-request.ts. On submit, switches the form to read-only and displays components/loading-status.tsx.
  2. Stop 2: Backend Orchestration & Guardrails (app/api/pitch/route.ts)
    Enforces per-IP rate limits (lib/security/rate-limit.ts), runs runtime schema checks, and initiates a 15-second AbortController in lib/ai/generate-pitch.ts.
  3. Stop 3: Structured AI Output & Presentation (components/pitch-deck.tsx and components/copy-actions.tsx)
    Renders 4 distinct satire cards in a 2x2 grid, highlights the CEO Verdict, and enables structured plain-text clipboard copying via lib/clipboard/format-pitch.ts.

“To Change This, Start Here”

Change the Humor / Tone

Edit the system prompt in lib/ai/providers/gemini-adapter.ts under SYSTEM_PROMPT.

Add or Modify Preset Chips

Update the SAMPLE_CONFESSIONS array in components/confession-form.tsx.

Change Clipboard Text Format

Update the formatted plain-text structure in lib/clipboard/format-pitch.ts.

Adjust Rate Limits or Timeouts

Modify parameters in lib/security/rate-limit.ts or DEFAULT_TIMEOUT_MS in lib/ai/generate-pitch.ts.

A Practice to Reuse

Strict Schema Validation on Untrusted AI Responses:

Instead of hoping an LLM outputs the right format and parsing it loosely on the frontend, Delulu CEO enforces a double barrier: Gemini's native responseSchema at generation time, followed by runtime verification via PitchResponseSchema.safeParse() on the server. If the shape is invalid, the API fails cleanly with an honest retry error rather than rendering broken or empty cards.
